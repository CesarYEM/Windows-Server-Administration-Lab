# Windows Server Administration Lab

## Overview
This project documents my hands-on practice with **Windows Server 2025** in a virtualized environment using VMware.

## Objectives
- Learn Windows Server administration.
- Configure Active Directory Domain Services (AD DS) and DNS.
- Manage domain users and security groups.
- Configure shared folders and access permissions.
- Test authentication and access control.
- Document troubleshooting steps and lessons learned.

## Environment
| Spec | Configuration |
| :--- | :--- |
| **Operating system** | Windows Server 2025 |
| **Virtualization** | VMware |
| **Memory** | 8 GB RAM |
| **CPU** | 4 virtual cores |
