# Windows-Server-Administration-Lab
Hands-on Windows Server 2025 lab using VMware to practice system administration, Active Directory, DNS, user and group management, storage, and access control.
Objectives

Learn Windows Server administration.

Configure Active Directory Domain Services (AD DS) and DNS.

Manage domain users and security groups.

Configure shared folders and access permissions.

Test authentication and access control.

Document troubleshooting steps and lessons learned.

Environment

Operating system: Windows Server 2025

Virtualization: VMware

Memory: 8 GB RAM

CPU: 4 virtual cores

Progress

Install Windows Server 2025.

Install Active Directory Domain Services and DNS.

Create and manage users and security groups.

Configure shared folders and permissions.

Test access using different user accounts.

Document results and troubleshooting.

Disclaimer

This project is a personal learning lab. All configurations and tests are performed in a controlled virtual environment.
